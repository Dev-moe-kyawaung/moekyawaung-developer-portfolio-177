## Local Development

This is a static portfolio and does not require a backend service.

```bash
git clone [https://github.com/Dev-moe-kyawaung/moekyawaung-developer-portfolio-177.git](https://github.com/Dev-moe-kyawaung/moekyawaung-developer-portfolio-177.git)
cd moekyawaung-developer-portfolio-177
```

Start a local server with Python:

```bash
python3 -m http.server 5500
```

Open:

```text
http://localhost:5500
```

Alternatively, use the Live Server extension in Visual Studio Code.

## Deployment

### GitHub Pages

1. Push the project to GitHub.
2. Open **Settings → Pages**.
3. Select **GitHub Actions** as the source.
4. Use the included Pages workflow.
5. Wait for the deployment to complete.
6. Open the generated GitHub Pages URL.

### Vercel

1. Import the repository into Vercel.
2. Select the project root as the deployment directory.
3. Leave the framework preset as **Other** for a static site.
4. Deploy the project.
5. Add a custom domain if required.
