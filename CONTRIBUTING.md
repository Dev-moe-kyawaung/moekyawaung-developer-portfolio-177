# Contributing

Thank you for your interest in this portfolio project.

## Before Contributing

- Read the project README.
- Check existing issues and pull requests.
- Avoid changing personal branding without discussion.
- Preserve responsive behavior.
- Keep the project dependency-light.
- Test changes on mobile and desktop layouts.

## Development Guidelines

- Use semantic HTML.
- Prefer reusable CSS classes.
- Keep JavaScript modular.
- Use descriptive names.
- Avoid unnecessary third-party scripts.
- Optimize images before committing.
- Preserve accessibility attributes.
- Do not commit credentials, tokens, or private information.

## Pull Requests

A pull request should include:

- A clear title.
- A concise explanation of the change.
- Screenshots for visual changes.
- Testing details.
- Any deployment considerations.

## Commit Style

Use clear commit messages:

```text
feat: add project showcase section
fix: improve mobile navigation
style: refine hero typography
docs: update deployment instructions
perf: optimize portfolio images
