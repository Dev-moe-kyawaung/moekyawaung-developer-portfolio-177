# Security Policy

## Supported Versions

Security fixes are applied to the latest version of the portfolio repository.

| Version | Supported |
| --- | --- |
| Latest main branch | Yes |
| Older deployments | No |
| Archived versions | No |

## Reporting a Vulnerability

Please do not publish security vulnerabilities in public issues.

Report potential vulnerabilities privately through the contact method listed on the owner's GitHub profile:

- GitHub: https://github.com/Dev-moe-kyawaung

Include:

- A clear description of the issue.
- Steps to reproduce it.
- Affected files or URLs.
- Potential impact.
- Suggested remediation, if available.

Please allow reasonable time for investigation and remediation before public disclosure.

## Sensitive Information

Never submit the following to the repository:

- API keys.
- Passwords.
- Access tokens.
- Private certificates.
- Firebase service-account files.
- Personal identity documents.
- Private client information.
